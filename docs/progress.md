### 収録リズム

**Samba Reggae 1曲のみ**（骨格はソンクラーベ 3-2 と同一、2/2 × 2小節）。

```
2/2 ‖: ♩. ♪ 𝄽 ♩ | 𝄽 ♩ ♩ 𝄽 :‖
```

BPM は2分音符で数える（カットタイム）。BPM 100 で1周期 2.4 秒。

### 仮のもの（本番までに差し替える）

- **音源が合成音。** 非整数比の倍音を重ねたアゴゴ風。本番はオーナーの録音に差し替える
- **アプリ名・アイコン・配色が未定**

- [ ] スマホのボイスメモで可。静かな部屋、マイクから30〜50cm、一定の強さで8〜10回
