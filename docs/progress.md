### 収録リズム

**Samba Reggae 1曲のみ**（骨格はソンクラーベ 3-2 と同一、2/2 × 2小節）。

```
2/2 ‖: ♩. ♪ 𝄽 ♩ | 𝄽 ♩ ♩ 𝄽 :‖
```

BPM は2分音符で数える（カットタイム）。BPM 100 で1周期 2.4 秒。

## 更新履歴

### 2026-08-20（2）

- **タップテンポを追加。** BPM 表示そのものがタップ面（`#tap`）
  - 直近5タップ＝4区間。**外れ値は「中央値との比」で判定する**（`1/1.4 〜 1.4`）。
    「区間 ms の ±40%」は BPM に直すと 0.71〜1.67 倍の非対称な窓になるため採らない
  - 範囲外（40 未満・240 超）は **clamp せず捨てて前の値を保つ**。
    240 超が出るのは「上限まで速くしたい」ではなく「叩き方が乱れた」
  - 時刻は `performance.now()`。逆行・同時刻・非有限は無視する
  - `pointerdown`（`isPrimary` かつ左ボタンのみ）と Enter / Space の両方で叩ける
- **入力層の検証を追加**（`normalizeBpm`）。
  `Number("")` も `Number(null)` も `Number(false)` も 0 を返すため、
  「有限数か」だけで通すと静かに 40 BPM へ化ける。数値と数字文字列だけ受ける
- **`Scheduler` の保留切替が単一スロットだったのを修正。**
  パターン変更の保留中にテンポ変更が来ると、パターン変更が消えていた。
  タップテンポは1打ごとにテンポ変更を撃つので、パターン一覧を作ると顕在化する
- BPM の下に「タップ：2分音符」を出す。同じ 120 BPM でも単位で速さが倍違う。
  Unicode の音符記号（U+1D15E 等）は iOS で豆腐になる端末があるので使わない
- 設計は codex にセカンドオピニオンを取り、上記の比率判定・clamp 方針・
  pending マージ・キーボード対応を反映した
